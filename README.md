# mutetalk

**mutetalk (n.) — talking for a while before noticing you are still on mute.**

## Why this word

Video calls gave us a brand-new way to embarrass ourselves: you answer a question, make your point, maybe even tell a little story, and only then spot the crossed-out microphone. Everyone who works, studies, or keeps in touch through a screen has done it at least once, yet English never gave that little performance a name of its own.

*Mutetalk* fills that gap. It is built from two plain roots, mute and talk, so the spelling and the sound are obvious the first time you see it, and it sits naturally beside words like smalltalk and sweettalk. The definition says the whole thing in one breath: you kept talking, and you were muted the whole time. No example is needed, because the moment the reader hears it, they can already picture themself doing it.

## Run

```bash
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

The program writes exactly one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), with no trailing newline, and checks on disk that the bytes it wrote are exactly the entry above.
